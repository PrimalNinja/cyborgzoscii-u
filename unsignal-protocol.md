### 1. OVERVIEW

UNSIGNAL Protocol is an advanced ZOSCII implementation designed to neutralize pattern recognition and heuristic analysis. By introducing randomized offsets and variable padding, it ensures that identical inputs never result in identical outputs, even when using the same ROM.

### 2. ARCHITECTURE

All addresses are stored in little-endian format. Every UNSIGNAL Protocol file begins with a 4-address header that dictates the state of the obfuscation layer.

#### The 4-Address Header:

1. Address 1 & 2 (ROM Pointer): These point to two random bytes in the ROM. These bytes are combined to form a 16-bit address pointer that defines the logical "start" of the ROM for the current session. The size of the ROM following this pointer value should still be at least 64KB for greatest security.

2. Address 3 (Prefix Length): Points to a random byte in the ROM with a value of 10 or greater. The value at this address determines the length of a randomly generated byte array to be used as a prefix.

3. Address 4 (Suffix Length): Points to a random byte in the ROM with a value of 10 or greater. The value at this address determines the length of a randomly generated byte array to be used as a suffix.



### 3. ENCODING STEPS

1.  Select Randoms: Generate random bytes for the 16-bit ROM start pointer (Low/High) and the Prefix/Suffix lengths.

2.  Map Header: Use standard ZOSCII logic to find addresses (H1, H2, H3, H4) in the ROM that contain these random values.

3.  Generate Noise: Create a prefix array and a suffix array of random bytes based on the lengths identified in Step 1.

4.  Encode Data: Perform the ZOSCII encoding of the message. (offset the search space based on the 16-bit pointer derived from H1/H2).

5.  Assemble: Concatenate [H1, H2, H3, H4] + [Prefix] + [Encoded Address Stream] + [Suffix].

### 4. DECODING STEPS

1.  Read Header: Extract the first 4 addresses (H1-H4).

2.  Calculate Offsets:
- low = ROM[H1]
- high = ROM[H2]
- prefix_len = ROM[H3]
- suffix_len = ROM[H4]

3.  Strip Noise:     
- Skip the first prefix_len bytes following the header.
- Terminate the stream suffix_len bytes before the end of the file.

4.  Extract Data: Use the remaining address stream to perform standard ZOSCII decoding against the ROM.
