# UNSIGNAL 프로토콜: 정보기관 분석 워크스루

**저자:** Julian Cassin  
**날짜:** 2026-03-11

1. 인터셉트
   - 원시 파일 획득: 헤더 없음, 매직 바이트 없음, 구조 없음
   - 파일 크기: 가변적 (무작위 접두사/접미사로 인해)
   - 메타데이터: 시간, 출처, 목적지 — 아무런 정보도 제공하지 않으며, 내용이나 의도와 연관될 수 없음

2. 통계 분석 (ent)
   - 엔트로피: 7.99+ 비트/바이트 (최대)
   - 압축률: 0% (완벽한 엔트로피)
   - 카이제곱: 무작위성 통과
   - 직렬 상관관계: 거의 0
   - 결과: 진정한 무작위 노이즈와 구별 불가능

3. 좌표계 혼동
   - 헤더 주소: ROM의 처음 64KB 내 절대 위치
   - 데이터 주소: H1/H2 간접 참조 자체에서 파생된 ROM 오프셋 기준 상대 위치
   - 동일한 파일 내 두 개의 서로 다른 좌표계
   - 공격자는 다음 없이 데이터 주소를 해석할 수 없음:
       a) H1/H2를 특별한 것으로 인식 (일반 데이터처럼 보임)
       b) H1/H2를 디코딩하여 오프셋 값 획득
       c) 오프셋을 적용하여 모든 후속 주소 재해석
   - ROM 없이 올바르게 추측할 확률: 0
   - ROM이 있더라도 헤더와 데이터 중 어떤 것이 주소인지 알아야 함
   - 헤더/데이터 우연 일치 확률: 1/65536

4. 트래픽 분석
   - 무작위 접두사/접미사가 실제 메시지 경계를 숨김
   - H3/H4 또한 그 자체로 간접 참조임
   - 가변적인 ROM 시작 오프셋은 세션별로 해석을 변경
   - 패킷 크기나 타이밍에 고정된 패턴 없음
   - 파일에 데이터가 있는지 비어 있는지 확인 불가

5. 리버스 엔지니어링
   - 인코더 획득: 한 줄짜리 조회 테이블 (공개)
   - 알고리즘: 단순함, 보안은 ROM(키)에 있음
   - 작동 방식을 아는 것은 아무런 이점도 제공하지 않음

6. 기지 평문 공격 시도
   - 동일한 평문을 두 번 인코딩 → 다른 출력
   - 문자당 여러 주소 옵션 (무작위 선택)
   - 악용할 수 있는 반복 가능한 패턴 없음

7. 키 복구
   - 무차별 대입: ITS, 정의상 불가능
   - 부채널 공격: 단순 조회, 유출될 복잡한 수학 없음
   - ROM은 물리적/법적 수단을 통해 획득해야 함

8. 검증 문제
   - 모든 ROM은 무언가를 디코딩함
   - 잘못된 ROM → 쓰레기 (하지만 실제처럼 보이는 쓰레기)
   - 체크섬, MAC, 성공 표시기 없음
   - 어떤 디코딩이 "올바른지" 확인할 수 없음

9. 조합 규모 (바람과 함께 사라지다 예시)
   - 단일 소설 인코딩: >10^5,500,000 가지 가능한 표현
   - 5개의 비반복 주소: 1조 가지 조합
   - 메모리가 소진될 때까지 추적: 불가능
   - 충돌 절대 없음

10. 완벽한 부인 가능성
    - 모든 디코딩은 내부적으로 일관됨
    - 모든 출력은 무작위 우연으로 일축될 수 있음
    - 외부 컨텍스트 없이는 "올바른" 디코딩이 정의되지 않음

11. 압축 동작
    - ZOSCII/UNSIGNAL 인코딩 파일은 압축되지 않음 (~0% 비율)
    - 출력이 이미 최대 엔트로피에 가까움
    - 크기 축소를 위해: 입력을 먼저 압축한 다음 인코딩
    - 인코딩된 결과는 입력에 관계없이 압축 불가능 상태 유지

12. 인증 및 변조 탐지는 내부에 있음
    - 필요한 경우 MAC: 인코딩된 페이로드 내부에 배치
    - 체크섬, 서명, 검증 데이터: 모두 메시지 내부에 포함
    - 동일한 인코딩 규칙 적용 — 무작위 노이즈와 구별 불가능해짐
    - 공격자는 인증 데이터와 메시지 내용을 구별할 수 없음
    - 외부 검증 마커 없음

13. 결론
    - 통계 도구 반환: 무작위 노이즈, 여기엔 아무것도 없음
    - 경계 은닉으로 인해 트래픽 분석 무력화
    - 키 복구는 수학이 아닌 ROM을 필요로 함
    - ROM 후보가 있어도 검증 불가능
    - 인증은 페이로드 내에 숨겨져 메시지와 구별 불가능
    - 압축은 인코딩 전에만 가능, 이후에는 불가능
    - 시스템이 인식론적 폐쇄를 달성: 공격자는 자신이 이겼는지 알 수 없음
