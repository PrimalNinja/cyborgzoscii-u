1 · ROM & ENCODE (build a target encoded text)

Non-"same" inner layers use the creator's general encoder (same objArgs). Micro layers read ROM 1 as nibbles, 2 per byte, high nibble first (same as MicroZOSCII.FromBytes). microZOSCII uses the first 256 nibbles; microUNSIGNAL and microBRICS slide a 256-nibble window.
Drop any file on the canvas to use it as the ROM (smaller ROM = smaller pool = more leakage).

2 · ATTACK (from file bytes only)

Custom attack: your file must define function attack(api). api gives only what an attacker holds: api.wire (file bytes), api.structures (4 readings: name, reading, parity, addrs), api.readAddrs(bytes,start), api.peel(bytes), api.crib / api.cribBytes, api.dictionary, api.allow / api.forbid, api.mode, api.log(text). May return a value or a Promise. It runs inside this page, so it could read the encoder panel too. An honest attack uses api only.
