## Overview

This demo turns two LEGO SPIKE Prime hubs into a quantum-proof, light-based communication system using ZOSCII encoding. One hub transmits messages as light pulses; the other receives and decodes them. No radio, no Wi-Fi, no encryption—just physics and mathematics.

The security is information-theoretic: the light pulses carry only addresses. Without the shared ROM, the pulses reveal nothing about the message.

---

## ROM Options

Two ROM sizes are provided, selectable via a flag in the main program.

### Option 1: 4KB ZOSCII ROM (Byte Addressing)

| Parameter | Value |
|-----------|-------|
| ROM size | 4,096 bytes |
| Instances per byte | 16 (average) |
| Security | 16^N combinations for N-byte message |
| Address range | 0–4095 (12 bits) |
| Transmission | Send 12-bit addresses as light pulses |

**Best for:** Full byte encoding, no nibble splitting. Good balance of security and transmission speed.

### Option 2: 256-Byte microZOSCII ROM (Nibble Addressing)

| Parameter | Value |
|-----------|-------|
| ROM size | 256 bytes |
| Instances per nibble | 16 |
| Security | 16^N combinations for N nibbles (N = 2 × message length) |
| Address range | 0–255 (8 bits) |
| Transmission | Send 8-bit addresses as light pulses, two per message byte |

**Best for:** Minimal memory footprint. Each message byte becomes two nibble addresses (high + low).

## ROM Module (`rom.py`)

Create this file on both hubs. It contains both ROM options as pre-generated bytearrays for fast import.

```python
# rom.py
# ZOSCII ROM Generator for Lego Mindstorms
# Provides two ROM options for the light communication demo

import array

# ============================================
# Option 1: 4KB ZOSCII ROM (Byte Addressing)
# ============================================
# Each byte value (0-255) appears 16 times
# Total size: 256 × 16 = 4096 bytes
# Security: 16^N combinations for N-byte message

ROM_4KB = bytearray(4096)
for i in range(4096):
    ROM_4KB[i] = i // 16  # Byte value repeats 16 times


# ============================================
# Option 2: 256-Byte microZOSCII ROM (Nibble Addressing)
# ============================================
# Each nibble value (0-15) appears 16 times
# Total size: 16 × 16 = 256 bytes
# Security: 16^(2N) combinations for N-byte message

ROM_256 = bytearray(256)
for nibble in range(16):
    for i in range(16):
        ROM_256[nibble * 16 + i] = nibble


# ============================================
# Helper Functions
# ============================================

def build_lookup_byte(rom):
    """Build lookup table for byte ROM: value → list of positions"""
    lookup = [[] for _ in range(256)]
    for idx, val in enumerate(rom):
        if val < 256:
            lookup[val].append(idx)
    return lookup


def build_lookup_nibble(rom):
    """Build lookup table for nibble ROM: nibble → list of positions"""
    lookup = [[] for _ in range(16)]
    for idx, val in enumerate(rom):
        if val < 16:
            lookup[val].append(idx)
    return lookup


# ============================================
# Encode Functions
# ============================================

def encode_byte_rom(rom, message, lookup):
    """Encode message using byte ROM (1 address per character)"""
    import random
    addresses = []
    for char in message:
        byte_val = ord(char)
        if byte_val < 256 and lookup[byte_val]:
            addr = random.choice(lookup[byte_val])
            addresses.append(addr)
    return addresses


def encode_nibble_rom(rom, message, lookup):
    """Encode message using nibble ROM (2 addresses per character)"""
    import random
    addresses = []
    for char in message:
        byte_val = ord(char)
        high_nibble = (byte_val >> 4) & 0x0F
        low_nibble = byte_val & 0x0F
        
        if lookup[high_nibble] and lookup[low_nibble]:
            high_addr = random.choice(lookup[high_nibble])
            low_addr = random.choice(lookup[low_nibble])
            addresses.append(high_addr)
            addresses.append(low_addr)
    return addresses


def decode_byte_rom(rom, addresses):
    """Decode addresses using byte ROM"""
    return ''.join(chr(rom[addr]) for addr in addresses if addr < len(rom))


def decode_nibble_rom(rom, addresses):
    """Decode addresses using nibble ROM (pairs of addresses become one byte)"""
    result = []
    for i in range(0, len(addresses), 2):
        if i + 1 < len(addresses):
            high = rom[addresses[i]] & 0x0F
            low = rom[addresses[i + 1]] & 0x0F
            byte_val = (high << 4) | low
            result.append(chr(byte_val))
    return ''.join(result)
```

## Transmitter Hub Code (`transmitter.py`)

```python
# transmitter.py
# LEGO SPIKE Prime ZOSCII Light Transmitter

import hub
import time
import random
from rom import ROM_4KB, ROM_256, build_lookup_byte, build_lookup_nibble
from rom import encode_byte_rom, encode_nibble_rom

# ============================================
# CONFIGURATION
# ============================================
# Set to True for 4KB byte ROM, False for 256-byte nibble ROM
USE_4KB_ROM = True

# Base pulse duration in milliseconds per address unit
# Address 0 = 1 × base, Address 255 = 256 × base, etc.
BASE_DURATION_MS = 1

# Pulse duration for end marker (short pulse)
END_MARKER_PULSE_MS = 50
END_MARKER_GAP_MS = 20

# Gap between address pulses
ADDRESS_GAP_MS = 50

# Message to send (default)
DEFAULT_MESSAGE = "HELLO WORLD"

# ============================================
# INITIALIZATION
# ============================================
if USE_4KB_ROM:
    ROM = ROM_4KB
    LOOKUP = build_lookup_byte(ROM)
    encode_func = encode_byte_rom
    MAX_ADDR = 4095
    print("Using 4KB byte ROM (12-bit addresses)")
else:
    ROM = ROM_256
    LOOKUP = build_lookup_nibble(ROM)
    encode_func = encode_nibble_rom
    MAX_ADDR = 255
    print("Using 256-byte nibble ROM (8-bit addresses)")

print(f"Base duration: {BASE_DURATION_MS}ms per unit")
print(f"Address range: 0-{MAX_ADDR} (pulse = (addr+1)×{BASE_DURATION_MS}ms)")

# ============================================
# LIGHT PULSE TRANSMISSION
# ============================================
def send_pulse(duration_ms):
    """Turn LED matrix on, wait, turn off"""
    hub.display.show(hub.Image("99999:99999:99999:99999:99999"))  # Full brightness
    time.sleep_ms(duration_ms)
    hub.display.clear()


def send_address(addr):
    """Send a single address as a pulse. Address 0 sends 1 × base (detectable)."""
    # Offset by +1 so address 0 produces a detectable pulse
    duration = (addr + 1) * BASE_DURATION_MS
    send_pulse(duration)
    time.sleep_ms(ADDRESS_GAP_MS)  # Gap between addresses


def send_start_marker():
    """Send start marker: 500ms pulse"""
    send_pulse(500)
    time.sleep_ms(100)


def send_end_marker():
    """Send end marker: three rapid pulses (unambiguous, cannot collide with data)"""
    for _ in range(3):
        send_pulse(END_MARKER_PULSE_MS)
        time.sleep_ms(END_MARKER_GAP_MS)
    time.sleep_ms(100)  # Extra gap before next message


def send_message(message):
    """Encode and send a full message"""
    addresses = encode_func(ROM, message, LOOKUP)
    
    print("Sending message:", message)
    print("Addresses:", addresses[:20], "..." if len(addresses) > 20 else "")
    print("Total pulses:", len(addresses))
    
    send_start_marker()
    
    for addr in addresses:
        send_address(addr)
    
    send_end_marker()
    print("Message sent")


# ============================================
# MAIN
# ============================================
# Display ready message on hub
hub.display.show(hub.Image("ARROW_R"))

print("ZOSCII Light Transmitter Ready")
print("Press left button to send default message")
print("Press right button to send custom message")

while True:
    if hub.button.left.is_pressed():
        send_message(DEFAULT_MESSAGE)
        time.sleep(2)
    
    if hub.button.right.is_pressed():
        send_message("ZOSCII ON LEGO")
        time.sleep(2)
    
    time.sleep_ms(100)
```

## Receiver Hub Code (`receiver.py`)

```python
# receiver.py
# LEGO SPIKE Prime ZOSCII Light Receiver

import hub
import time
from rom import ROM_4KB, ROM_256, decode_byte_rom, decode_nibble_rom

# ============================================
# CONFIGURATION
# ============================================
# Must match transmitter setting
USE_4KB_ROM = True

# Base pulse duration in milliseconds (must match transmitter)
BASE_DURATION_MS = 1

# End marker detection: three short pulses (< 100ms each)
END_MARKER_THRESHOLD_MS = 100

# ============================================
# INITIALIZATION
# ============================================
def init_sensor(port='A'):
    """Initialize color sensor with firmware compatibility fallback"""
    sensor = hub.port[port].device
    try:
        # SPIKE Prime / Robot Inventor (v3.2.0+)
        sensor.mode(0)  # Reflected light intensity
    except:
        try:
            # Alternative for some firmware versions
            sensor.mode('REFLECT')
        except:
            # Fallback: assume default mode is reflected light
            pass
    return sensor


if USE_4KB_ROM:
    ROM = ROM_4KB
    decode_func = decode_byte_rom
    MAX_ADDR = 4095
    print("Using 4KB byte ROM (12-bit addresses)")
else:
    ROM = ROM_256
    decode_func = decode_nibble_rom
    MAX_ADDR = 255
    print("Using 256-byte nibble ROM (8-bit addresses)")

print(f"Base duration: {BASE_DURATION_MS}ms per unit")
print(f"End marker: three pulses < {END_MARKER_THRESHOLD_MS}ms")

# ============================================
# LIGHT PULSE RECEPTION
# ============================================
def measure_pulse_duration(sensor, timeout_ms=5000):
    """Measure the duration of a light pulse"""
    start_time = time.ticks_ms()
    
    # Wait for light to turn on
    while time.ticks_diff(time.ticks_ms(), start_time) < timeout_ms:
        if sensor.get_reflected_light() > 20:  # Threshold for "light on"
            pulse_start = time.ticks_ms()
            # Wait for light to turn off
            while sensor.get_reflected_light() > 20:
                if time.ticks_diff(time.ticks_ms(), pulse_start) > timeout_ms:
                    return None
            return time.ticks_diff(time.ticks_ms(), pulse_start)
        time.sleep_ms(1)
    return None


def receive_message():
    """Receive a full message. Returns list of addresses."""
    addresses = []
    pulse_history = []  # Store last 3 pulse types (True = short)
    
    while True:
        duration = measure_pulse_duration(sensor)
        if duration is None:
            # No pulse within timeout - end of transmission
            break
        
        # Classify pulse: short (< threshold) or long (>= threshold)
        is_short = duration < END_MARKER_THRESHOLD_MS
        pulse_history.append(is_short)
        
        # Keep only last 3 pulses
        if len(pulse_history) > 3:
            pulse_history.pop(0)
        
        # Check for end marker: three shorts in a row
        if len(pulse_history) == 3 and all(pulse_history):
            print("End marker detected")
            break
        
        # Only long pulses are data addresses
        if not is_short:
            # Reverse the offset: addr = (duration / base) - 1
            addr = round(duration / BASE_DURATION_MS) - 1
            if 0 <= addr <= MAX_ADDR:
                addresses.append(addr)
                print(f"Address: {addr}")
            else:
                print(f"Warning: Address {addr} out of range, skipping")
    
    return addresses


# ============================================
# MAIN
# ============================================
# Initialize color sensor
sensor = init_sensor('A')

# Display waiting indicator
hub.display.show(hub.Image("ARROW_L"))

print("ZOSCII Light Receiver Ready")
print("Waiting for transmission...")

while True:
    # Wait for start marker (long pulse > 300ms)
    duration = measure_pulse_duration(sensor, timeout_ms=5000)
    if duration and duration > 300:
        print("Start marker detected")
        addresses = receive_message()
        
        if addresses:
            message = decode_func(ROM, addresses)
            print(f"Decoded: {message}")
            print(f"Received {len(addresses)} addresses")
            
            # Display on hub screen
            hub.display.show(hub.Image("YES"))
            time.sleep(2)
            hub.display.show(hub.Image("ARROW_L"))
        else:
            print("No addresses received")
    
    time.sleep_ms(100)
```

## How to Run

### 1. Program Both Hubs

| Hub | Files to Upload |
|-----|-----------------|
| **Transmitter** | `rom.py`, `transmitter.py` |
| **Receiver** | `rom.py`, `receiver.py` |

### 2. Configure

Set `USE_4KB_ROM` to the same value on both hubs:
- `True` for 4KB byte ROM (faster transmission per byte)
- `False` for 256-byte nibble ROM (smaller memory footprint)

### 3. Connect Hardware

- **Transmitter:** No external sensors (uses built-in LED matrix)
- **Receiver:** Plug color sensor into Port A

### 4. Position Hubs

- Place receiver's color sensor facing transmitter's LED matrix
- Distance: 5-10 cm, clear line of sight
- Avoid bright ambient light that might interfere with detection

### 5. Run

1. Power both hubs
2. Press left button on transmitter to send "HELLO WORLD"
3. Receiver will display a checkmark when message received
4. Press right button to send "ZOSCII ON LEGO"

## Communication Protocol

| Element | Encoding |
|---------|----------|
| **Start marker** | 500ms pulse |
| **Address** | Pulse duration = (address + 1) × BASE_DURATION_MS (min 1 × base) |
| **Address gap** | 50ms between address pulses |
| **End marker** | Three rapid pulses of 50ms each, 20ms gaps (unambiguous) |

### Transmission Time Estimates

| ROM | Addresses per byte | Max address | Max pulse per address | Time per byte (max) |
|-----|-------------------|-------------|----------------------|-------------------|
| 4KB | 1 | 4095 | 4.096 seconds | ~4.1 seconds |
| 256B | 2 | 255 | 0.256 seconds | ~0.5 seconds |

*Note: For practical demos, keep messages short. BASE_DURATION_MS can be reduced to 0.1 (100 microseconds) for faster transmission, but may require better sensor sensitivity.*

## Protocol Robustness Features

| Issue | Solution |
|-------|----------|
| **Address 0 invisible** | Offset by +1: pulse = (addr + 1) × base |
| **End marker collision** | Three rapid pulses (unambiguous; cannot occur in valid data) |
| **Sensor API compatibility** | Try/except fallback for different firmware versions |
| **Noise rejection** | Pulse length classification with thresholds |

---

## Security Properties

| Property | Why |
|----------|-----|
| **No encryption** | Light pulses carry addresses, not encrypted data |
| **Information-theoretic security** | Without the ROM, addresses reveal nothing about the message |
| **Combinatorial security** | 4KB ROM: 16^N combinations; 256B ROM: 16^(2N) combinations |
| **Air-gapped by physics** | No radio frequency; only line-of-sight light |
| **Plausible deniability** | Any ROM decodes to something; the correct message cannot be proven |

## Comparison of ROM Options

| Factor | 4KB ZOSCII | 256B microZOSCII |
|--------|------------|------------------|
| **ROM size** | 4,096 bytes | 256 bytes |
| **Instances per byte/nibble** | 16 per byte | 16 per nibble |
| **Message bytes per address** | 1 byte per address | 2 addresses per byte |
| **Address bits** | 12 bits (0–4095) | 8 bits (0–255) |
| **Transmission bits per byte** | 12 bits | 16 bits |
| **Max pulse per address** | 4.096 seconds (@1ms/unit) | 0.256 seconds (@1ms/unit) |
| **Security (per byte)** | 16 possibilities | 256 possibilities |
| **Memory footprint** | Larger | Minimal |

## Troubleshooting

| Problem | Likely Cause | Solution |
|---------|--------------|----------|
| No light detected | Sensor not facing LED matrix | Align sensor directly at LED matrix, 5-10cm distance |
| False end markers | Ambient light interference | Reduce ambient light or increase threshold |
| Missing addresses | BASE_DURATION_MS mismatch | Ensure both hubs use same value |
| Sensor mode error | Firmware version | Check tested firmware v3.2.0+; try alternative mode |
